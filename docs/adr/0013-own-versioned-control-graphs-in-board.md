# Own versioned Control graphs in Gareji Board

Gareji Board will own immutable Control graph revisions, named entries, typed routes, Project graph bindings, Route decisions, Graph anchors, and Graph rewrite proposals. Gareji Safe Autopilot may select only declared routes through deterministic policy; a model may propose a route or rewrite but cannot create hidden topology or silently mutate an in-flight revision. Runner receives a concrete selected stage, while Gareji Core continues to evaluate only concrete capabilities and progress without importing Board graph semantics. This keeps project routing inspectable and reversible, separates organizational control from Work item dependencies, and preserves human goals, frozen rules, approvals, and Core policy as independent authority boundaries.
