# Evidence-first delivery

Inspect the current project and Work item before changing source code. Record independently checkable evidence, then use that evidence to choose the smallest bounded implementation and verification path.

The approach is project-independent: a Runtime Binding supplies the concrete project, Work item, Agent profile, and Execution workspace only after Safe Autopilot has validated an application proposal.
