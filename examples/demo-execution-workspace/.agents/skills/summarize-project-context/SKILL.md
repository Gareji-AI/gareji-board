# Summarize Project Context

Use only the context sources and execution workspace supplied by Gareji Board. Do not search unrelated notes or other connected projects.

## Workflow

1. Read the supplied project note, work-item context, and applicable workspace instructions.
2. Inspect only the minimum execution-workspace metadata needed to confirm repository identity and current state.
3. Separate confirmed facts from inference. Attach a source path or evidence reference to every material claim.
4. Return purpose, current state, constraints, open questions, and the safest next action.
5. Report missing or conflicting context as a blocker. Do not silently invent project intent.

Do not modify project files, Board state, or knowledge sources.
