# Gareji Board demo workspace

This is a disposable Markdown knowledge workspace for the bundled Gareji Board demo. It contains no personal notes and does not require Obsidian.

The directories under `4_Project` are imported as Board projects. Their Markdown files provide project context; source code remains in separately connected execution workspaces.

## Included projects

- Gareji Board — the portfolio interface and local work state.
- Gareji Core — trusted execution, compact results, and audit evidence.
- Zettelkasten Plugin — the first independently managed Knowledge Adapter product.

Future GBrain, LLMWiki, and runtime plugins will each receive their own product project instead of being grouped into one `Gareji Plugins` project.

Agent instructions and Skills live in the separate `examples/demo-execution-workspace` fixture. This Knowledge workspace contains context only and does not act as executable agent configuration.
