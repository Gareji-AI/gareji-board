# Gareji Board

## Purpose

Make multi-project AI work visible and controllable without requiring users to write orchestration code.

## Current focus

- Show project and work-item state clearly.
- Explain why Autopilot selected or skipped work.
- Connect each project to its own knowledge and execution workspaces.

## Completion signal

A new user can open the bundled workspace, run one safe task, and understand its result and evidence.
