# Zettelkasten Plugin

## Purpose

Connect a Markdown Zettelkasten to Gareji Board without requiring Obsidian or treating one folder layout as part of the Zettelkasten method.

## Current focus

- Discover projects from a configurable workspace directory such as `4_Project`.
- Preserve the source path for every imported project and context item.
- Keep project notes separate from the repositories in which agents execute work.

## Completion signal

The Board imports this bundled project directory and shows each discovered product project with traceable Markdown context.
